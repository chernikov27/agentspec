# AgentSpec Brand Brief

## Brand

**Name:** AgentSpec

**English slogan:** Turn any API into an agent-ready x402 service.

**Russian slogan:** Превратите любой API в x402-сервис, готовый для AI-агентов.

## One-Liner

AgentSpec inspects OpenAPI specs, MCP tools, and API documentation, then generates agent-ready schemas, risk notes, readiness scores, and x402 Bazaar metadata.

AgentSpec анализирует OpenAPI-спецификации, MCP tools и API-документацию, а затем генерирует схемы, оценки готовности, заметки о рисках и metadata для x402 Bazaar.

## What AgentSpec Does

AgentSpec helps developers, API companies, and MCP builders package existing APIs into services that AI agents can understand, evaluate, call, and pay for through the x402 protocol.

The product focuses on the layer between "I have an API" and "AI agents can reliably use and buy this API":

- API and OpenAPI inspection
- MCP tool inspection
- Agent-readiness scoring
- Tool schema generation
- x402 Bazaar metadata generation
- Endpoint description cleanup
- Usage examples and response examples
- Basic risk and clarity notes

## Target Users

- Developers building x402 endpoints
- MCP server builders
- API companies that want agent-native distribution
- DevRel and infrastructure teams
- Marketplaces or catalogs that need cleaner service listings

## Core Promise

AgentSpec makes APIs discoverable, understandable, and ready for autonomous agents.

## Brand Direction

The selected logo direction is a compass/radar/scout mark combined with angle brackets and a central agent node. It should communicate:

- discovery
- API understanding
- agent readiness
- technical precision
- trust without feeling like a cybersecurity-only product

## Visual Style

- Premium developer-tool SaaS
- Clean, technical, and trustworthy
- Light neutral backgrounds
- Deep navy, electric cyan, teal, and controlled coral accents
- Gradients are allowed, but should stay polished and restrained
- Avoid crypto-trading visual cliches
- Avoid looking like a legal, compliance, or security-only product

## Landing Page Direction

The landing page should open directly with the product promise, not a generic marketing hero.

Suggested hero copy:

**AgentSpec**

Turn any API into an agent-ready x402 service.

Inspect OpenAPI specs, MCP tools, and API docs. Generate agent-ready schemas, readiness scores, risk notes, and x402 Bazaar metadata in one call.

Primary CTA:

Inspect an API

Secondary CTA:

View example report
